# קפסולת ארון — Capsule Wardrobe
# 30 פריטים · 100+ לוקים · מותאם לאקלים ישראלי

---

## עקרונות הקפסולה

1. **פלטה של 3+2** — 3 ניטרליים (שחור/נייבי/לבן/בז'/אפור) + 2 צבעי אקצנט מהעונה האישית.
2. **כל פריט חייב להתחבר ל-3 פריטים אחרים לפחות.** אם לא — הוא לא נכנס.
3. **70/30** — 70% ליבה תמידית, 30% טרנד/עונתי מתחלף.
4. **איכות מעל כמות** בפריטי-על: מעיל · נעליים · תיק · בלייזר. שם ההשקעה משתלמת.
5. **One-In-One-Out** ברגע שהקפסולה מלאה.

## חלק ד' — עץ החלטה לרכישה

```
האם יש לי כבר פריט שממלא את אותו תפקיד?
├─ כן → האם החדש טוב ממנו משמעותית?
│        ├─ כן → קנה + הוצא את הישן (One-In-One-Out)
│        └─ לא → ❌ אל תקנה
└─ לא → האם הוא מתחבר ל-3+ פריטים בארון?
         ├─ לא → ❌ אל תקנה (זה "יתום")
         └─ כן → מה ה-CPW?
                  ├─ < ₪10  → ✅ קנה
                  ├─ ₪10-30 → 🤔 חכה 48 שעות. עדיין רוצה? קנה.
                  └─ > ₪50  → ❌ רק אם זה פריט השקעה/אירוע יחיד
```

**CPW = מחיר ÷ מספר לבישות צפוי בשנתיים**
